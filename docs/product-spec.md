# FieldProof product specification

FieldProof is an AI-native service-outcome and margin operating layer for residential pest-control operators. Its north star is contribution profit per technician-day, balanced with first-visit resolution, evidence completeness, route density, and reservice liability.

## Core loop

Request → Triage → Plan → Schedule → Prepare → Inspect → Document → Complete → Verify → Follow up → Measure → Learn

The MVP proves this loop for a fictional Huntley basement rodent concern. It uses deterministic policy and economics for final operational decisions. AI is narrow: classification, extraction, summarization, and plain-language explanation.

## Primary surfaces

- Control Tower: operational metrics and work requiring attention.
- Service Requests: structured triage with source traceability.
- Schedule: eligible slots ranked by expected contribution and route fit.
- Technician Job: mobile brief, checklist, observations, evidence, and unresolved risk.
- Service Proof: customer-facing facts and follow-up.
- Property Intelligence: living property memory and risk history.
- Exceptions and Audit: approval-oriented control plane and decision trace.
